规范要点对照
·§3.1 一步式入口（点击上传 = 新建行 + 立即开始）；行内 3 态：上传中 / 上传成功 / 失败，全在单行内切换（"上传成功"对应内部 staging 状态）
·§3.2 进度条 4px，紧贴文件名下方，百分比同步
·§3.3 操作仅 3 个：删除（全态）/ 替换（上传成功）/ 重试（失败）
·§3.4 任意行上传中→提交置灰；存在失败行→置灰
·§4 前端 业务侧自定义重名规则的校验，选择即拦截（按钮下方红字 4-5s 自动消失），不入子表占位行
·§5.3 staging 过期：commit 时检测后阻止提交
·§5.5 重试默认从头；启用断点续传则从中断进度继续
